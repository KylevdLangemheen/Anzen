## Required Discord Permissions
1. Ban Members (move role downwards for less power)
2. View Audith Log
3. View relevant notification-channel
4. Send Messages in relevant notification-channel (or thread created in that channel)

## Configuration Setting
1. Restrict usage under: Server Settings -> Integrations -> Anzen -> Command Permissions (just clicking Cross X at Roles & Members @everyone and Channels All channels restricts it to admin-only)
2. Type `/configure` to set everything up
